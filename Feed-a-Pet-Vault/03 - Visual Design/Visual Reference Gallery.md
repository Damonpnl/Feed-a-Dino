# Visual Reference Gallery

Curated, not exhaustive. Every image is **Steal an Egg reference material**, not Feed a Pet art or a requirement. IDs resolve in [[04 - Reference Research/Reference Manifest]]. "Adapt" means a lesson may inform a future task; it is never a copy instruction. Open an image only when a task is visual.

**Coverage gap.** No image of Feed a Pet's own in-game visuals is stored here. Studio's `screen_capture` returned the viewport to the agent only (no file), and in Play the 3D world rendered black on 2026-10-21 (the HUD rendered). The live HUD is described in [[03 - Visual Design/UI Screens and Contracts]]. Missing: overview map, each zone, bases, resource fields, guardians, pets, evolution UI as images.
