# Asset Specification

- **Gameplay id:** existing string id. Do not invent a parallel name
- **Display name:**
- **Role:** pet, guardian, resource, station, UI icon
- **Evidence level:** proposal or approved
- **Silhouette:** one sentence a player can read at chase distance
- **Accent:** one material or color
- **Scale reference:** player height or guardian body box
- **Collision:** separate from decorative spikes
- **Attachment:** carry grip or station root
- **Model key:** `ResourceModels` or pet `Visual.ModelKey`
- **Not included:** copyrighted reference shapes. Link the reference still as inspiration only

See [[03 - Visual Design/Art Direction]] and [[03 - Visual Design/Creatures and Asset Specifications]].
